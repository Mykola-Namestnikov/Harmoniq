# Harmoniq

Harmoniq — платформа для публікації та читання статей.
Відвідувачі можуть переглядати статті та профілі авторів,
а зареєстровані користувачі — створювати власні публікації
з фотографіями, зберігати матеріали в закладки
та переглядати власні й збережені статті у профілі.

Застосунок має адаптивний інтерфейс для мобільних пристроїв,
планшетів і комп’ютерів.
